# Certificates Asset Directory

This directory stores web-accessible, deployment-safe certificate files for your portfolio.
These files are automatically served by Vite and deployed together with your website on Netlify/GitHub Pages.

### Included Certificate Assets:
- `pega-internship-preview.svg` : High-resolution vector preview thumbnail for the Pega National Internship Program certificate.
- `pega-internship.pdf` : Downloadable certificate PDF accessible at `/certificates/pega-internship.pdf`.

### How to use your own certificate scan:
If you have an official PDF or high-resolution PNG/JPG scan from Pega / SmartBridge:
1. Copy your certificate PDF file into this folder and name it:
   `pega-internship.pdf`
2. (Optional) If you have an image scan (PNG or JPG), save it as:
   `pega-internship.png` or `pega-internship.jpg`
3. The portfolio will immediately display and serve your updated document!
