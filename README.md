- **Interactive Hero Section**: Highlighting technical focus areas, ECE background, and direct access to resume & projects.

- **Engineering Projects Showcase**: Interactive filterable cards detailing architecture, tech stack, and GitHub source code.
- **Interactive Timeline & Education**: Academic progression at V.S.B. Engineering College (8.40 / 10 CGPA) and school distinctions.
- **7 Verified Certifications**: Coursework credentials from **NIELIT**, **CISCO Networking Academy**, **Infosys Springboard**, **Salesforce**, and **HP Foundation**.
- **Responsive Dark Theme UI**: Built with modern glassmorphism design, ambient glowing background accents, and seamless mobile drawer navigation.

## 💻 Getting Started Locally

Follow these steps to run the portfolio locally on your machine:

### Prerequisites

- **Node.js** (v18.0 or higher recommended)
- **npm** (v9.0 or higher)

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Dharun-07-byte/VSBEC.git
   cd VSBEC
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start the Local Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser to view the portfolio.

4. **Build for Production**:
   ```bash
   npm run build
   ```
